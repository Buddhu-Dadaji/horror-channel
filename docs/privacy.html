Privacy Policy

Last updated: 22 November 2026

1. What this application does

Kaali Raatein is a personal content-publishing tool. It generates short horror videos and uploads them to the operator's own YouTube channel and Instagram account. There are no end users to sign up.

2. Data collected

The application stores no personal data on a server. Generated videos and a JSON progress log live in a private GitHub repository. Access tokens are stored as encrypted GitHub Actions secrets.

3. YouTube API Services

This application uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The application requests the youtube.upload scope only, and uses it solely to upload videos to the operator's own channel. It does not read viewer data, subscriber lists or analytics beyond the video IDs it creates.

4. Instagram

The application uses the Instagram Platform API with the instagram_business_basic and instagram_business_content_publish permissions, to publish videos to the operator's own professional account.

5. Third parties

Media is hosted transiently on catbox.moe and Cloudflare R2 so Instagram can retrieve it. Images are generated via Pollinations. Narration is synthesised via Microsoft Edge TTS.

6. Revoking access

Access can be revoked at any time at Google Account permissions and in the Instagram app under Settings → Apps and websites.
